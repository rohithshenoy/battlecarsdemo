# battlecarsdemo
A simple WebGL app to demo Cursor Cloud Agents capabilities

You can change the spaceship color at launch with `--spaceship-color=r,g,b`, where each value is between `0.0` and `1.0`. For example: `./SpaceInvaders --spaceship-color=1.0,0.0,0.0`

## Controls

| Key | Action |
|-----|--------|
| Left / A | Move left |
| Right / D | Move right |
| Space (hold) | Fire |
| Shift + Space (hold) | Turbo fire — rapid shots, faster bullets (orange) |
| Escape | Quit |
